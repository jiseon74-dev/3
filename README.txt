덕트속도 · 덕트정압 계산기 - GitHub Pages 설치형 웹앱 패키지

이 패키지는 GitHub Pages의 /3/ 경로에 배포하도록 설정되어 있습니다.

포함 파일
- index.html: 계산기 본체
- manifest.json: 이 앱 전용 ID, 시작 주소, 범위 및 아이콘 설정
- sw.js: 이 앱 경로 안에서만 동작하는 서비스 워커
- icon-192.png, icon-512.png: 앱 아이콘

설치 방법
1. 저장소에서 3 폴더 안의 기존 파일을 삭제합니다.
2. 이 ZIP의 압축을 풉니다.
3. 압축을 푼 폴더 안의 파일 5개를 저장소의 3/ 폴더에 직접 업로드합니다. ZIP 파일 자체를 폴더에 올리는 것이 아닙니다.
4. 배포 완료 후 https://jiseon74-dev.github.io/3/manifest.json 및 /sw.js 가 열리는지 확인합니다.
5. 휴대폰 크롬에서 https://jiseon74-dev.github.io/3/ 를 열고 설치합니다.

중요
- 이 앱의 manifest id / start_url / scope는 /3/로 고정되어 다른 앱과 구분됩니다.
- 반드시 두 ZIP을 각자의 폴더에 올리세요. 파일을 서로 바꾸거나 루트 폴더에 올리지 마세요.
- 기존 홈 화면 앱 아이콘을 삭제한 뒤 크롬에서 사이트를 다시 열어 재설치하세요.
- 배포 후에도 이전 화면이면 크롬 탭을 닫고 사이트 데이터를 지우거나 잠시 기다렸다 다시 접속하세요.
